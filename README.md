# PW Manager

Лаунчер клиентов Perfect World для Windows: хранит серверы, аккаунты и персонажей,
запускает выбранных клиентов и раскладывает их окна.

## Возможности

- **Серверы** — отдельная папка и свой `elementclient.exe` у каждой версии игры.
- **Аккаунты и персонажи** — все персонажи сервера в одном списке; каждый
  запускается со своим логином и паролем.
- **Запуск по галочкам** — отметил нужных, нажал `Play`; программа ждёт окончания
  загрузки каждого клиента по нагрузке процессора.
- **Список персонажей** — иконка класса, состояние (`Off` — не запущен,
  `Run` — запускается, `Play` — запущен, `Min` — свёрнут) и номер монитора.
- **Раскладка окон** — лесенка внутри монитора; порядок задаётся перетаскиванием
  и запоминается. Окна остаются на своих мониторах, размер не меняется.
- **Панель задач** — до семи кнопок запущенных клиентов, переключение на окно.
- Вывести окно клиенты на передний план либо двойным щелчком мыши по нику в окне программы, либо по иконке в панели задачь.
- **Справка** — `F1` или `Help → Open help`.

## Установка

1. Распакуйте архив в любую папку (например, `D:\Games\PWM`).
2. Запустите `PWMenadger.exe`.
3. Добавьте сервер кнопкой `+` у списка `Servers` — выберите `elementclient.exe`.

Права администратора не нужны, если программа лежит в пользовательской папке.

## Данные

Рядом с `PWMenadger.exe`:

- `pwm_data.json` — серверы, аккаунты, персонажи, очередь окон, позиция окна;
- `icons\` — иконки классов (`.ico`).

Для резервной копии достаточно скопировать эти два объекта. Пароли в базе
закодированы, но это не шифрование — храните файл в месте, доступном только вам.

## Обновления

При запуске программа один раз проверяет манифест `latest.json` (адрес задан в
программе) и, если вышла новая версия, показывает окно с описанием изменений и
ссылкой на скачивание. Автоматической замены файлов нет — новую версию
устанавливает пользователь.

Формат манифеста:

```json
{
  "version": "2.1.5",
  "url": "https://github.com/<логин>/pwm/releases/latest",
  "notes": "- что изменилось"
}
```

## Требования

- Windows 10 или Windows 11, 64-бит.
- Установленный клиент Perfect World (свой для каждой версии игры).
